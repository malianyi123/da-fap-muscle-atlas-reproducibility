# Large data files

The following files are part of the complete reproducibility package but are not committed directly to GitHub because they exceed normal repository file-size limits:

- `da_fap_data_package.tar.gz` (~2.9 GB)
- processed single-cell and spatial `.h5ad` objects listed in `release_packages/large_data_manifest/MANIFEST.tsv`

Checksums for these files are provided in:

- `release_packages/large_data_manifest/SHA256SUMS.txt`

These large processed objects will be deposited on Zenodo upon acceptance. Until then, they can be regenerated from public GEO/CELLxGENE source data using the scripts in this repository.
